## Why These Changes Exist

The failing labels combine connector lifecycle, offload scheduling, and
distributed execution. The PR should explain whether it fixes:

- finished-transfer accounting;
- scheduler ownership or cleanup;
- NIXL worker shutdown;
- offloaded block lifecycle;
- test script configuration.

Those are different failure classes and should not be blurred together.
