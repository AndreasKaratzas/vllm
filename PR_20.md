This should not be posted as a real PR. It is a holding area for files that do

command. The goal is to make it impossible for miscellaneous changes to hide
inside a large ROCm CI patch.

## Rule For Promotion Out Of This Bucket

A file can leave this bucket only when it has:

- an exact `.buildkite/test-amd.yaml` label or focused pytest;
- a before/after failure explanation;
- a reason the change belongs with the target PR;
- a validation command.
