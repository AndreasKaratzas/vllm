## Failure Basis

Known examples from the investigation:

- ModernBERT dtype behavior differed on ROCm when `dtype=torch.float16` was
  passed in a path that did not behave like CUDA.
- Multimodal processor/model tests needed ROCm-specific dependency or processor
  behavior to avoid CPU/GPU setup failures.
- Speech/multimodal models need architecture-specific handling rather than
  broad accuracy waivers.
