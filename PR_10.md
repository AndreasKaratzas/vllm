## Why These Changes Exist

The earlier failure mode was that DeepSeek V4 registration could find one
implementation but not the AMD one. The registry layer needs to expose AMD and
NVIDIA variants in a way that matches the package layout and platform selection.

The AMD model files appear to be adapted from the NVIDIA DeepSeek V4 model
structure with AMD attention/MLA differences. That is a valid approach only if
the PR makes the copied lineage explicit and keeps platform-specific changes
small and reviewable.
