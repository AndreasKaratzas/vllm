## Failure Pattern

The Buildkite logs showed failures during worker device initialization and
process-group setup:

- `RuntimeError: No HIP GPUs are available` inside Ray worker startup.
- `NCCL error: unhandled cuda error` followed by HIP `invalid argument`.
- Failures appeared in both test-style jobs and model accuracy jobs that create
  multi-process TP/EP workers.

That points at process environment, visible-device mapping, or worker lifecycle,
not a single model-specific numerical issue.

## Why The Changes Might Be Needed

- Distributed tests need to create and tear down process groups cleanly so one
  test does not poison later tests in the same container.
- Elastic EP state must not leave stale rank/device assumptions when workers
  are restarted or scaled.
- KV connector utility changes may be necessary if connector setup is run in
  the same multi-process environment as the failing jobs.
